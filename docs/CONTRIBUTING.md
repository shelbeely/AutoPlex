# Contributing to AutoPlex

We welcome contributions to improve the AutoPlex media LLM system! Please take a moment to review this document before submitting your work.

## How to Contribute
1. Fork the repository and create a new branch
2. Make your changes following the guidelines below
3. Submit a pull request with a clear description of your changes

## Code Style Guidelines
- Follow PEP8 for Python code
- Use descriptive variable names
- Keep functions focused on a single responsibility
- Add docstrings to all public modules, functions, and classes
- Maintain consistent mermaid diagram formatting for documentation

## Feature Development
- New features should include:
  - Unit tests
  - Documentation updates
  - Example queries in README
  - Integration with existing metadata schema

## Bug Reports
When reporting bugs, please include:
1. Detailed steps to reproduce
2. Expected vs actual behavior
3. System information (OS, Python version)
4. Any error messages or logs

## Security Considerations
- All contributions must maintain our safety and security standards
- Sensitive data handling should follow our security policy
- New dependencies must be reviewed for vulnerabilities
